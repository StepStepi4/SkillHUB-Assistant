# Оформлення тексту в таблиці

Пишіть у клітинці таблиці — застосунок перетворить розмітку на заголовки, жирний, кольори, розділювачі й блоки.
Спробувати наживо: сторінка `Format.html` (редактор + шпаргалка).


## Рядкове оформлення

| Пишете | Результат |
|---|---|
| `/текст/` | заголовні літери |
| `//текст//` | жирні ЗАГОЛОВНІ |
| `*текст*` | жирний |
| `_текст_` | курсив |
| `++текст++` | підкреслений |
| `~текст~` | закреслений |
| `==текст==` | виділення маркером |
| `^текст^` | більший розмір |
| ``КОД-123`` | код: торкнутися = скопіювати |

## Колір і стиль

| Пишете | Результат |
|---|---|
| `{r\|текст}` | червоний (r червоний, g зелений, b синій, y жовтий, o помаранчевий, p фіолетовий, s сірий, t бірюзовий) |
| `{зелений\|текст}` | колір можна писати словом |
| `{#ff6600\|текст}` | або кодом |
| `{r,ж,велико\|Увага}` | колір + жирний + великий (ж жирний, к курсив, п підкреслений, з закреслений, верх ЗАГОЛОВНІ, велико, величезно, мало, моно) |
| `{g!\|НОВИНКА}` | знак ! = кольорова плашка |

## Рядки і розділювачі

| Пишете | Результат |
|---|---|
| `# Великий заголовок` |  |
| `## Середній заголовок` |  |
| `### Малий заголовок` |  |
| `---` | тонка лінія |
| `===` | товста лінія |
| `...` | пунктирна |
| `***` | зірочки |
| `~~~` | хвиляста |
| `---Розділ---` | лінія з назвою |
| `[br]` | порожній проміжок; [br 30] = 30 пікселів |
| `[центр] текст` | вирівнювання: [центр] [право] [ліво] |

## Списки

| Пишете | Результат |
|---|---|
| `- перший<br>- другий` | маркований список |
| `1. крок<br>2. крок` | нумерований |
| `[x] зроблено<br>[ ] не зроблено` | чекліст |

## Блоки

| Пишете | Результат |
|---|---|
| `[[ Заголовок картки<br>текст<br>- пункт<br>]]` | картка (рамка) |
| `[2]<br>Ліва колонка<br>[\|]<br>Права колонка<br>[/]` | колонки: [2] [3] [4], між ними [\|], кінець [/] |
| `[+] Детальніше<br>прихований текст<br>[/+]` | розгортається по дотику |
| `\| Назва \| Ціна \|<br>\|---\|---\|<br>\| Товар \| 100 \|` | таблиця (рядок \|---\| робить шапку) |

## Правила

- Позначки пишуться впритул до тексту: `*так*`, а не `* так *`.
- Усередині слова чи числа позначки не діють: `км/год`, `10/11/2026`, `5*3` лишаються як є.
- Позначки можна вкладати: `//Увага: *важливо*//`.
- Старий формат описів послуг працює: `|` = новий рядок, `+Підзаголовок`, `=МІТКА`, емодзі на початку = іконка, `"Назва послуги"` = ціна.
- Розмітка діє в описах послуг, оновленнях (changelog) та теорії курсів Академії.
- Екранування: `\*` показує зірочку як є.
